# Summit 2 · Laboratorio Unidades 8 & 9

App de práctica (React + Vite + TypeScript + Tailwind).

## Local
```
npm install
npm run dev
```

## Vercel
1. Sube esta carpeta a un repositorio de GitHub (o usa `vercel` desde la terminal).
2. En Vercel: Add New → Project → importa el repo.
3. Vercel detecta Vite solo: Build Command `npm run build`, Output Directory `dist`. Deploy.
